# Blumenstrauß 💐

Ein rotierender 3D-Blumenstrauß aus Textzeichen, der im Browser aufblüht – mit Sternen,
Sternschnuppen, kleinen Feuerwerken und schwebenden Blüten rundherum.

**Live ansehen:** https://sluj00.github.io/bouquet3d/

- Klicken oder Tippen lässt den Strauß neu aufblühen.
- Den Text unten änderst du in `index.html` bei `MESSAGE`.

Basiert auf dem Terminal-Programm `bouquet3d.py` von Alish Sharma (MIT-Lizenz, siehe `LICENSE`
und `ORIGINAL_README.md`). Die Browser-Version ist eine Übersetzung nach JavaScript mit
Aufblüh-Animation, Glow und zusätzlichen Effekten.
